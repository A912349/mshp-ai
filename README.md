# Распознавание жестов руки — Flask + камера браузера

## 1. Идея проекта

Проект представляет собой веб-приложение для распознавания жестов руки в реальном времени. Камера открывается **в браузере пользователя**, после чего отдельные кадры отправляются на Flask-сервер. Сервер обрабатывает кадр через **MediaPipe Hand Landmarker**, рисует ключевые точки кисти и возвращает результат обратно на страницу.

Сценарий использования: демонстрация простого управления жестами.

## 2. Почему камера именно клиентская

В старой архитектуре с `cv2.VideoCapture(0)` камера открывается на той машине, где запущен Python/Flask. Если приложение запустить на сервере, то оно будет пытаться взять камеру сервера, а не пользователя.

В этой версии используется правильная веб-архитектура:

1. Браузер клиента получает доступ к камере через `navigator.mediaDevices.getUserMedia()`.
2. JavaScript берёт кадр из видео и отправляет его на endpoint `/process_frame`.
3. Flask backend обрабатывает кадр через MediaPipe.
4. Backend возвращает обработанную картинку и JSON с количеством пальцев, жестом и FPS.
5. Браузер показывает результат пользователю.

## 3. Что умеет приложение

- получает видеопоток с камеры клиента;
- не использует `cv2.VideoCapture(0)`;
- запускает модель MediaPipe для поиска ключевых точек кисти;
- рисует каркас руки: линии и точки;
- считает количество поднятых пальцев;
- определяет простой жест;
- корректно выводит русский текст на кадре через Pillow;
- показывает результат в браузерном интерфейсе Flask;
- предоставляет `/status`, `/health` и `/process_frame` endpoints.

## 5. Установка

Рекомендуется Python 3.10 или 3.11.

```bash
python -m venv .venv
```

Активация окружения:

**Windows:**

```bash
.venv\Scripts\activate
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Скачивание модели:

```bash
python scripts/download_model.py
```

Или вручную:

```bash
curl -L -o models/hand_landmarker.task https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```

## 6. Запуск

```bash
python app.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5000
```

Рекомендуется использовать docker:

```bash
docker compose up --build -d
```

Нажмите кнопку **«Включить камеру»** и разрешите браузеру доступ к камере.

### Важно про ошибку «браузер не поддерживает камеру»

`getUserMedia()` работает только в безопасном контексте. Надёжные варианты:

- `http://127.0.0.1:5000`;
- `http://localhost:5000`;
- сайт через HTTPS.

Если открыть проект как обычный файл через `file://` или с другого устройства через `http://IP_КОМПЬЮТЕРА:5000`, браузер может скрыть API камеры и приложение покажет ошибку. Это не значит, что камера сломана. Это ограничение безопасности браузера.

## 7. Запуск на другом устройстве в одной сети

Если Flask запущен на одном компьютере, а открыть страницу нужно с телефона или другого ноутбука, в `app.py` можно заменить:

```python
app.run(host="127.0.0.1", port=5000, debug=False, threaded=True)
```

на:

```python
app.run(host="0.0.0.0", port=5000, debug=False, threaded=True)
```

После этого откройте в браузере клиента:

```text
http://IP_КОМПЬЮТЕРА:5000
```

Важно: браузеры обычно разрешают камеру на `localhost` и `127.0.0.1`. Если страница открывается с телефона или другого компьютера через обычный `http://IP_КОМПЬЮТЕРА:5000`, камера, скорее всего, будет заблокирована. Для такого сценария нужен HTTPS.

## 8. Пример входных и выходных данных

**Входные данные:** кадры с камеры клиента, отправленные браузером на backend.

**Выходные данные:**

- изображение с отрисованными точками и линиями руки;
- количество найденных рук;
- количество поднятых пальцев;
- название жеста;

Пример JSON-ответа `/process_frame`:

```json
{
  "image": "data:image/jpeg;base64,...",
  "state": {
    "hands_count": 1,
    "fingers_count": 5,
    "gesture": "Открытая ладонь / стоп",
    "fps": 12.4,
    "frames": 320,
    "updated_at": 1710000000.0
  }
}
```

## 10. Дополнительные фишки

В проект добавлены функции:

- **История жестов** — справа отображаются последние устойчиво распознанные жесты с временем.
- **Снимок результата** — кнопка «Снимок» сохраняет обработанный кадр или кадр камеры через браузер.
- **Переключение качества** — режимы «Экономное», «Обычное» и «Чёткое» меняют размер отправляемого кадра, частоту обработки и JPEG-качество.
- **Сетка кадра** — помогает показать, как рука расположена относительно камеры.
- **Полноэкранный режим** — удобно выводить результат на проектор.
- **Светлая/тёмная тема** — тема сохраняется в `localStorage` браузера.
- **Смена камеры** — на устройствах с несколькими камерами можно попробовать переключиться между передней и задней камерой.
